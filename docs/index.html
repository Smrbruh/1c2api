Список «Номенклатура»

Возвращает постранично список элементов справочника «Номенклатура». Используйте параметры $top и $skip для пагинации.

query Parameters
$top
integer [ 1 .. 1000 ]
Default: 100

Максимальное количество возвращаемых элементов (OData $top)

$skip
integer >= 0
Default: 0

Количество пропускаемых элементов (OData $skip)

$filter
string

Строка фильтрации в стиле OData (e.g. Активен eq true)
