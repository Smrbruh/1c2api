# 1C2API

**Конфигурация 1С → Современный API-контракт**

> Парсит конфигурацию 1С (EDT XML или `.cf`) и автоматически генерирует OpenAPI спецификацию, Swagger UI, Postman коллекцию, Markdown документацию и SDK на TypeScript / Python / Go.

**Статус:** `В разработке` — MVP ожидается через 2–3 недели.

---

## Проблема

Интеграция 1С с внешними системами — это боль. Каждый раз: ручное создание HTTP-сервисов, написание документации, поддержка SDK. На среднюю конфигурацию уходит **1–2 недели**.

## Решение

```bash
python -m 1c2api config.xml --output ./api
```

**5 минут** — и у тебя готов полный API-контракт.

## Быстрый старт

### Требования

- Python 3.11+
- Для EDT-выгрузки: просто файлы XML из EDT
- Для `.cf` / `.cfe`: установленный **1С:Предприятие** (лицензия обязательна)
- Для генерации SDK: [openapi-generator-cli](https://github.com/OpenAPITools/openapi-generator)

### Установка

```bash
git clone https://github.com/bakdauletsotsial/1c2api
cd 1c2api
pip install -r requirements.txt
```

### Использование

**EDT XML:**
```bash
python -m 1c2api ./my-config --output ./api
```

**Бинарная конфигурация `.cf`:**
```bash
python -m 1c2api ./my-config.cf --output ./api
```

**Результат в `./api/`:**
```
api/
├── openapi.yaml
├── swagger-ui/
│   └── index.html
├── postman.json
├── api.md
└── sdk/
    ├── typescript/
    ├── python/
    └── go/
```

## Архитектура

```
1С: Конфигурация
    │
    ├── EDT XML ──────────────────────────┐
    └── .cf / .cfe → CFAdapter (1cv8.exe) ┘
                                          │
                                    EDTParser
                                    (Python + lxml)
                                          │
                                  Pydantic Models
                              (Catalog, Document, Field)
                                          │
                                  JSON Schema
                              (единственный источник истины)
                                          │
                  ┌───────────────┬───────┴───────┬──────────────┐
                  │               │               │              │
              OpenAPI          Postman        Markdown         SDK
           (+ Swagger UI)    Collection     API Reference   (TS/Py/Go)
```

**Главный принцип:** JSON Schema — единый источник истины. Все генераторы берут данные из неё. Добавить новый генератор — значит написать один модуль поверх готового ядра.

## Принципы проекта

- **Сначала код, потом архитектура** — один работающий парсер ценнее трёх абстрактных классов
- **JSON Schema — единственная истина** — все генераторы берут данные из неё
- **Не пишем свои SDK** — OpenAPI Generator делает это лучше
- **Честный README** — никаких обещаний, которые не подкреплены кодом
