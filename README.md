# 1C2API

**1С конфигурациясы → Заманауи API-контракт**

> 1С конфигурациясын (EDT XML немесе `.cf`) парсингтейді және автоматты түрде OpenAPI спецификациясын, Swagger UI, Postman коллекциясын, Markdown құжаттамасын және TypeScript / Python / Go тілдерінде SDK генерациялайды.

**Күйі:** `Әзірленуде` — MVP 2–3 аптадан кейін күтілуде.

---

## Мәселе

1С-ті сыртқы жүйелермен интеграциялау — бұл ауыр жұмыс. Әр жолы: HTTP-сервистерді қолмен жасау, құжаттама жазу, SDK қолдау. Орташа конфигурацияға **1–2 апта** кетеді.

## Шешім

```bash
python -m 1c2api config.xml --output ./api
```

**5 минут** — және толық API-контракт дайын.

## Жылдам бастау

### Талаптар

- Python 3.11+
- EDT-шығарымы үшін: EDT-тен алынған XML файлдары
- `.cf` / `.cfe` үшін: орнатылған **1С:Кәсіпорын** (лицензия міндетті)
- SDK генерациясы үшін: [openapi-generator-cli](https://github.com/OpenAPITools/openapi-generator)

### Орнату

```bash
git clone https://github.com/bakdauletsotsial/1c2api
cd 1c2api
pip install -r requirements.txt
```

### Пайдалану

**EDT XML:**
```bash
python -m 1c2api ./my-config --output ./api
```

**Бинарлық `.cf` конфигурациясы:**
```bash
python -m 1c2api ./my-config.cf --output ./api
```

**`./api/` ішіндегі нәтиже:**
```
api/
├── openapi.yaml
├── swagger-ui/
│   └── index.html
├── postman.json
├── api.md
└── sdk/
    ├── typescript/
    ├── python/
    └── go/
```

## Архитектура

```
1С: Конфигурация
    │
    ├── EDT XML ──────────────────────────┐
    └── .cf / .cfe → CFAdapter (1cv8.exe) ┘
                                          │
                                    EDTParser
                                    (Python + lxml)
                                          │
                                  Pydantic Models
                              (Catalog, Document, Field)
                                          │
                                  JSON Schema
                                (бірыңғай ақиқат көзі)
                                          │
                  ┌───────────────┬───────┴───────┬──────────────┐
                  │               │               │              │
              OpenAPI          Postman        Markdown         SDK
           (+ Swagger UI)    Collection     API Reference   (TS/Py/Go)
```

**Басты қағида:** JSON Schema — бірыңғай ақиқат көзі. Барлық генераторлар деректерді одан алады. Жаңа генератор қосу — дайын ядроның үстіне бір модуль жазу дегенді білдіреді.

# 1C2API

**Конфигурация 1С → Современный API-контракт**

> Парсит конфигурацию 1С (EDT XML или `.cf`) и автоматически генерирует OpenAPI спецификацию, Swagger UI, Postman коллекцию, Markdown документацию и SDK на TypeScript / Python / Go.

**Статус:** `В разработке` — MVP ожидается через 2–3 недели.

---

## Проблема

Интеграция 1С с внешними системами — это боль. Каждый раз: ручное создание HTTP-сервисов, написание документации, поддержка SDK. На среднюю конфигурацию уходит **1–2 недели**.

## Решение

```bash
python -m 1c2api config.xml --output ./api
```

**5 минут** — и у тебя готов полный API-контракт.

### Установка

## Архитектура

```
1С: Конфигурация
    │
    ├── EDT XML ──────────────────────────┐
    └── .cf / .cfe → CFAdapter (1cv8.exe) ┘
                                          │
                                    EDTParser
                                    (Python + lxml)
                                          │
                                  Pydantic Models
                              (Catalog, Document, Field)
                                          │
                                  JSON Schema
                              (единственный источник истины)
                                          │
                  ┌───────────────┬───────┴───────┬──────────────┐
                  │               │               │              │
```

**Главный принцип:** JSON Schema — единый источник истины. Все генераторы берут данные из неё. Добавить новый генератор — значит написать один модуль поверх готового ядра.

## Принципы проекта

- **Сначала код, потом архитектура** — один работающий парсер ценнее трёх абстрактных классов
- **JSON Schema — единственная истина** — все генераторы берут данные из неё
- **Не пишем свои SDK** — OpenAPI Generator делает это лучше
- **Честный README** — никаких обещаний, которые не подкреплены кодом
